# Mission Overview

This laboratory focuses on cloud data engineering and object storage. The mission involved deploying MinIO as an S3-compatible object storage server using Docker, accessing its web console, creating a bucket, and uploading a test object.

# Objectives

* Differentiate Block, File, and Object Storage.
* Deploy an S3-compatible Object Storage server using Docker.
* Access the MinIO web interface through port forwarding.
* Create a bucket and upload an object.
* Document the deployment and activities using Markdown.

# Tools Used

* KillerCoda Ubuntu/Docker Playground
* Docker
* MinIO
* GitHub
* Web browser
* Linux command line

# Skills Learned

* Understanding different cloud storage types
* Using Docker to deploy a storage service
* Working with Docker ports and environment variables
* Accessing a web-based cloud storage console
* Creating buckets and uploading objects
* Documenting technical work using Markdown
* Using Linux command-line commands
